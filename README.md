# Velvet Android — corrected build

This version has an Android-inspired lock screen and home screen. Swipe up to unlock, swipe left/right between app pages, and tap icons to open Notes, Calendar, Gallery, Focus, Search, Settings, Project, or your social profiles.

## Publish on GitHub Pages
1. Extract this ZIP on your computer.
2. In `SERAKS10/velvet-android`, upload/replace `index.html`, `manifest.webmanifest`, `sw.js`, and the `assets` folder at the repository root.
3. Commit to `main` and wait for Pages to redeploy.
4. If the old interface is cached, press Ctrl+F5 or clear the site's cached data.

## Privacy
This package includes 31 media files from the available uploads. The repository is public, so anyone can view or download these files. Only publish photos and videos you are comfortable sharing publicly. This is not a private gallery.

## Notes and calendar
Notes and custom events are stored in this browser's local storage and do not sync automatically between devices. Birthdays appear as markers on the monthly calendar.
